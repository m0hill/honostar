# HonoStar

Monorepo containing:

- `packages/core` — the framework package (`@honostar/core`)
- `apps/starter` — minimal starter app (recommended starting point)
- `apps/demo` — the original, more complete example app

## Quick Start

```bash
pnpm install
pnpm dev
```

- Starter runs at `http://localhost:3000` (default).
- Run the full demo with `pnpm dev:demo`.
